Kontrol segmen untuk memilih satu dari dua sampai empat opsi yang selalu terlihat.

**Anda menyediakan:** `options` (`[{value, label}]`), `value`, `onChange(value)` dan `label` untuk kelompok.

- Cocok untuk interval, durasi atau mode ("30 dtk", "1 mnt", "5 mnt"). Lebih dari empat opsi: pakai daftar.
- Label singkat; setiap opsi minimal 44px tinggi dan berbagi lebar sama.
- Opsi terpilih berisi `accent` dengan teks `on-accent`.
