Indikator kemajuan: bar untuk persentase dan titik untuk hitungan langkah kecil.

**Anda menyediakan:** `variant` (`bar` atau `dots`), untuk bar `value` (0-100) dan `label`, untuk titik `total` dan `filled`.

- Bar: progres menuju level berikutnya. Sertakan angka dalam teks di dekatnya ("Tinggal 3 hari lagi").
- Titik: ketukan yang tersisa saat menyalakan api atau memecahkan es; titik terisi berisi `accent`, kosong hanya cincin `accent`.
- Keduanya diumumkan sebagai gambar dengan label yang menyebut jumlahnya.
