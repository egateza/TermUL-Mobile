Baris pengaturan dengan label, deskripsi opsional dan sakelar 48x28.

**Anda menyediakan:** `label`, `description`, `checked` dan `onChange(nextValue)`.

- Seluruh baris adalah target sentuh (`role="switch"`), minimal 64px.
- Label menyebut apa yang dinyalakan ("Biometrik untuk membuka vault"), bukan sebaliknya ("Matikan ...").
- Deskripsi menyebut akibatnya dan batasnya ("Hanya setelah konfirmasi pertama di tiap sesi").
- Sakelar mati memakai tepi `line-strong`; hidup memakai isian `accent`.
