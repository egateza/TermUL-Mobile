Tombol persegi untuk tombol khusus di atas keyboard dan di panel semua tombol.

**Anda menyediakan:** `label` (teks tombol), `ariaLabel` (nama panjang, mis. "Panah atas"), `pressed` untuk pengubah yang menahan (Ctrl, Alt, Shift) dan `onClick`.

- Label mono 14px; glyph hanya panah, backspace dan enter.
- Pengubah yang menahan memakai `pressed` dan menyala dengan isian `accent`; tombol biasa tidak memakai `pressed`.
- Minimal 44x44px. Baris tombol bisa digulir mendatar; jangan mengecilkan tombolnya.
