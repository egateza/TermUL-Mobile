Panel yang naik dari bawah untuk keputusan atau detail, dengan sudut atas `radius-3xl`.

**Anda menyediakan:** `title`, `children` (isi), `actions` (biasanya dua `Button`) dan `onClose` bila ada tombol tutup. Wadah luar (scrim, posisi absolut ke bawah) disediakan pemakai.

- Susunan tetap: pegangan, judul, isi, tombol. Tombol utama di kanan dan lebih lebar; tombol batal selalu ada.
- Untuk keputusan berisiko, tampilkan isi yang akan dikirim dan konsekuensinya di dalam isi, dan jadikan pilihan aman sebagai tombol utama.
- Isi yang panjang digulir di dalam sheet; tinggi maksimal sekitar 84% layar.
