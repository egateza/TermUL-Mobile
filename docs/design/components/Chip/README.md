Chip ringkas dalam tiga bentuk: filter (tombol), tag (label statis) dan level (kapsul mono berwarna level).

**Anda menyediakan:** `variant` (`filter`, `tag`, `level`), untuk filter `selected` dan `onClick`, untuk tag `tone` (`neutral`, `accent`, `bad`, `ok`, `ice`), untuk level `level` (1-9).

- Filter: tinggi 44px, satu terpilih dalam satu baris yang bisa digulir mendatar.
- Tag: hanya informasi; tag berisiko berbunyi "berisiko", bukan hanya berwarna merah.
- Level: tulis "Lv 3 · Api Merah" atau "Tanpa level"; warnanya diambil dari `level-n`.
