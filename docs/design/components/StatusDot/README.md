Titik status bersama katanya.

**Anda menyediakan:** `status` (`online`, `offline`, `busy`, `idle`) dan, bila perlu, `label` untuk menimpa kata bawaan.

- Warna tidak pernah berdiri sendiri: `online` hijau, `offline` merah dan `busy` amber selalu disertai kata, karena `ok` dan `bad` hampir sama terang.
- Kata bawaan: "online", "offline", "menyambung ulang", "siaga".
- Latensi ditambahkan di `HostRow` ("online · 18 ms").
