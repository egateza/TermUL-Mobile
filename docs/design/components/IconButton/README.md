Tombol persegi 44px yang isinya hanya ikon.

**Anda menyediakan:** `icon`, `label` (wajib, menjadi nama aksesibilitas), `tone` (`plain`, `filled`, `accent`), `pressed` untuk tombol yang bisa dinyalakan, dan `onClick`.

- Selalu isi `label` dengan kata kerja ("Tutup", "Tambah host").
- Gunakan `pressed` untuk keadaan menyala (isian `accent`), bukan mengganti ikonnya.
- Jangan memperkecil di bawah 44px.
