Wadah dengan tepi 1px dan sudut `radius-xl`.

**Anda menyediakan:** `children`, `tone` (`surface`, `inset`, `selected`), `padding` (`none`, `md`, `lg`) dan, bila bisa diketuk, `as`, `href` atau `onClick`.

- `surface` untuk kartu biasa; `inset` (`ground-deep`) untuk isi teknis seperti pratinjau perintah; `selected` memberi tepi `accent`.
- Pisahkan dengan tepi, bukan bayangan.
- Kartu yang bisa diketuk wajib minimal 44px tinggi dan punya nama yang jelas.
